🔑 First time? Add your YouTube API Key

This app talks to YouTube's API directly from your browser. You need a free API key. It only takes 2 minutes:

  1. Go to Google Cloud Console
  2. Create a project (or pick an existing one)
  3. Click APIs & Services → Enable APIs → search "YouTube Data API v3" → Enable it
  4. Click APIs & Services → Credentials → Create Credentials → API Key
  5. Copy the key and paste it below

🔒 Your key is saved only in your browser's localStorage — never sent to any server except Google's YouTube API.
